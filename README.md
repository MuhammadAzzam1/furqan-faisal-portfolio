# Furqan Faisal Portfolio

Premium, responsive portfolio for an AI-driven systems and backend developer.

## Preview locally

Open `index.html` directly, or serve this folder with any static web server.

## Fiverr profile

Paste the public Fiverr profile URL into `fiverrUrl` at the top of `script.js`. The Fiverr link stays hidden until a URL is provided.

## Deploy

Deploy the `furqan-portfolio` folder as a static Vercel project with no build command.
